# Local\_Share

Local\_Share is a cross-platform file-sharing application that enables seamless file transfers over Wi-Fi between devices such as iOS, Android, macOS, and Windows. This project is under active development and aims to provide a simple and efficient way to share files locally without the need for internet connectivity.

## 🚀 Features

* Cross-platform support (iOS, Android, macOS, Windows)
* Local file sharing over Wi-Fi
* Simple and lightweight

## ⚡ Current Status

This project is currently under construction. Core backend functionality has been started, but the frontend interface and detailed setup instructions are pending implementation.

## 🛠️ Tech Stack

* Python (backend)
* Node.js (dependency management)
* HTML / CSS / JS (frontend)
